ABOUT ME

모호한 요구사항도 명확한 결과물로 만드는, 김현지입니다.

화면 구조와 사용자 흐름을 정리하고, HTML/CSS/JS로 직접 구현해 배포까지 해낸 경험이 있습니다.
실무에서 Figma 프로토타입 기반 React 페이지 구현과 쇼핑몰 웹 페이지 레이아웃 재설계를 수행했고, 모바일 게임 두 종은 기획부터 구현, 광고 연동, 스토어 출시까지 혼자 진행했습니다.

3~10인 규모의 여러 팀 프로젝트에서 팀장과 부팀장을 맡아 협업하며 핵심 기능 구현을 직접 담당했습니다.

불편함이나 필요가 보이면 직접 만들어 해결합니다. 이미지 크기 변환이 번거로워 이모티콘 리사이저를, 출시한 게임에 활용하고자 Steam 리뷰 분석 웹앱을 제작했습니다.
작업할 때는 전체 구조를 먼저 설계하고 핵심 기능을 구현한 뒤 UX를 다듬으며, 계획한 범위를 우선 완성한 후 추가 기능과 개선점을 검토합니다.
